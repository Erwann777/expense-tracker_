# 💸 Expense Tracker

A modern, feature-rich personal finance app built with Flutter — track expenses, scan receipts, get AI-powered budget advice, and manage savings goals.

---

## ✨ Features

- 📊 **Expense & Income Tracking** — Add, edit, and categorize transactions
- 🤖 **AI Budget Advisor** — Groq-powered LLM gives personalized monthly spending advice
- 🧾 **Receipt Scanner** — Google Gemini Vision auto-extracts amount, merchant, date & category from receipt photos
- 💱 **Multi-Currency Support** — Live exchange rates via Open Exchange Rates API (6-hour cache)
- 🔁 **Recurring Expenses** — Set up automatic recurring transactions
- 🎯 **Savings Goals** — Track progress toward financial goals
- 📄 **PDF Reports** — Generate and share monthly expense reports
- 🔐 **PIN Lock & Auth** — Secure the app with a PIN + Firebase Auth
- 🌙 **Dark / Light Theme** — System-aware theming

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) `^3.11.4`
- A Firebase project (for auth & Firestore)
- A [Groq API key](https://console.groq.com) (free) — for AI Budget Advisor
- A [Gemini API key](https://aistudio.google.com) (free) — for Receipt Scanner

### 1. Clone the repo

```bash
git clone <your-repo-url>
cd expense-tracker_/new_app
```

### 2. Install dependencies

```bash
flutter pub get
```

### 3. Configure environment variables

Create a `.env` file in the `new_app/` directory:

```env
GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
```

> **Never commit `.env` to Git** — it is already listed in `.gitignore`.

### 4. Firebase Setup

- Add your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) to the respective platform folders.
- The `lib/firebase_options.dart` is auto-generated by FlutterFire CLI.

### 5. Run the app

```bash
flutter run
```
